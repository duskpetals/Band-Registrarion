# Web Registration System (User & Band)

This project is a front-end web application developed as part of a Web Development course assignment. It provides two separate registration forms: one for users and one for bands, with built-in validation and responsive design.

---

## Features

### User Registration
- Username, email, and password validation
- Personal information (name, birthdate, gender)
- Country selection via dropdown menu
- Address, city, and phone input
- Clean and responsive layout

---

### Band Registration
- Band account creation with authentication fields
- Band-specific details:
  - Band name
  - Music genre
  - Description
  - Number of members
  - Year founded
  - City, phone, website, and photo
- Advanced input validation using patterns

---

### Styling & UI
- Custom CSS with reusable components
- Styled buttons, dropdowns, and radio inputs
- Background images for visual appeal
- Responsive design using media queries
- Bootstrap integration for layout and components

---

## Technologies Used

- **HTML5** – Structure and form elements  
- **CSS3** – Custom styling and responsiveness  
- **Bootstrap 5** – UI components and layout  
- **JavaScript** – (linked for future enhancements)  

---

## Form Validation

The project uses **HTML5 validation** with regex patterns to ensure:
- Proper username format
- Strong password requirements
- Valid email structure
- Controlled numeric ranges (e.g., members, year)
- Text-only inputs where required

---

## Navigation

- Toggle button between:
  - User Registration (`register.html`)
  - Band Registration (`band_register.html`)
- Seamless switching between pages
